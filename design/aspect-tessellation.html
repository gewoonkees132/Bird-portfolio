Kees Leemeijer.   Aspect-ratio tessellation

Goal — pick a module/gutter combo where common photo aspect ratios land cleanly on integer cell spans, then design tessellations using only "big" slots (no postage stamps). Constant gutter rule preserved — 24px everywhere. The only variable is module size and grid extent.

Tessellation options — fewer photos, larger slots

Each tile fits 5–7 photos using only ratios from the kept set (3:2, 2:3, 4:3, 3:4, 16:9, 21:9, 1:1). No slots smaller than ~360 wide. Establishing viewport (dashed blue) shows how the arrangement reads on landing.
