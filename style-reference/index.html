Elevation

3 stack levels static + dynamic

This static grid is designed to be composed above a dynamic pannable background. Future portfolio surfaces stack from a pannable photo plane below, through this static UI grid, to focus overlays and labels on top.

  1. Above — focus overlays / labels
  2. Foreground — static UI grid (this)
  3. Background — pannable photo plane
FOCUS — KEYBOARD-VISIBLE

2px solid var(--blue) outline at 2px offset, 1px radius. Applied via :focus-visible on the runtime root so mouse clicks don't trigger the ring; only keyboard focus does.
