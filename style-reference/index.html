--field is uncoated-paper cream (Steidl monograph stock, not a screen background). --blue is Munich '72 lineage: high-saturation structural blue. --charcoal is quiet ink — photographic neutral, not pure black, so type sits at the same density as photographic shadows. --blue-soft is reserved for surfaces (borders, rules, dividers); for text use full --blue.

PHOTOGRAPH TREATMENT — AMBIENT VS FOCUSED
ambient — opacity 0.55 · saturate 0.65 · brightness 0.92
focused — opacity 1 · no filter · shadow lift

Non-focused photographs recede in attention but do not disappear: the photograph in focus is the subject; everything else is evidence. The ambient state is set on every .photo by default; .is-focused overrides it.

Aspect — 3:2 is canonical (35mm full-frame; the grid math is built around it). Other aspects render at the same height: landscape crops horizontally via object-fit: cover; portrait band-pads with the placeholder gradient. Square crops are disallowed (they break the 3:2 tessellation math).

SECTION-STAT HIGHLIGHT — <b> PATTERN
9 colssystem-unit count — highlighted 2 partsanatomical subdivision — plain

<b> wraps the numeric in section-stats when the count refers to a system unit the brand catalogues (cols, tokens, sizes, slots, primitives, demos, principles). When the count refers to anatomical subdivisions of one specimen (parts, states), the numeric stays plain. Color is --blue 500 via the .sr-section__stats b rule.

Tokenized type sizes (--wm-size, --label-size, --meta-size) are reusable across components; the display roles above are one-offs for specific rendered moments. New display roles earn their place by being named here first; freelance sizes elsewhere are drift.

Elevation

3 stack levels static + dynamic

This static grid is designed to be composed above a dynamic pannable background. Future portfolio surfaces stack from a pannable photo plane below, through this static UI grid, to focus overlays and labels on top.

  1. Above — focus overlays / labels
  2. Foreground — static UI grid (this)
  3. Background — pannable photo plane
FOCUS — KEYBOARD-VISIBLE

2px solid var(--blue) outline at 2px offset, 1px radius. Applied via :focus-visible on the runtime root so mouse clicks don't trigger the ring; only keyboard focus does.

Captions a single bird photograph. One per cell, anchored bottom-left. Formula — line-name in English title-case; latin in lowercase scientific binomial form (Genus species, italic, --blue); meta as Photo X / N with non-breaking spaces. If no settled binomial exists, use the most-recent published name; never coin one.

Tells the visitor how to navigate the photo plane and where they currently are. Formula — instruction line: imperative verbs separated by a middle-dot (Drag · arrow keys); state line: Arrangement {single uppercase letter} with the letter in .arr at the wider tracking. No emoji; no icons.
